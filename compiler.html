How does this work?

🖥 Runs in your browser

JavaScript, TypeScript, Python, Ruby, Lua, SQL and HTML/CSS run on your own device using WebAssembly. Your code never leaves the browser. The first run of Python or Ruby downloads its interpreter, which can take a few seconds.

☁️ Runs on a server

C, C++, Java, Go, Rust, C#, Kotlin, PHP, Swift, Bash, R, Haskell, Perl and Scala need a real compiler, so they're sent to a sandboxed compile server. Sign in to use them. Runs are limited to a few seconds and 256 MB.

💾 Saved automatically

Your code for each language is saved in this browser as you type. Use Share to get a link with your code in it.
