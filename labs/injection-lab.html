Prompt Injection Lab

First, train your eye: which of these everyday inputs is secretly trying to give an AI orders? Then play security engineer and choose the defenses for an AI agent under attack.

Beginner~12 minNot completed yet

Part 1: Spot the injection

An AI assistant is about to read each of these. Decide whether it's safe or contains an injection. Hidden text is revealed after you answer.

Part 2: Defend the agent

A user asks their AI assistant: “Summarise this web page for me.” The assistant can read the page, read the user's private notes, send email and load web links. The page has been booby-trapped. Pick an attack, choose your defenses and run it.

⚙ Simulated agent: scripted to behave like a gullible model. No real AI is called.

What the lab shows

  • Keywords aren't the signal. A customer saying "ignore my previous ticket" is harmless. A polite request hidden in a CV is not. What matters is untrusted text trying to direct the AI.
  • Filters catch some attacks, never all. "Spotlighting" stopped the blunt attack and missed the polite one.
  • Architecture beats detection. Removing tools the task doesn't need, and blocking ways for data to leave, contain attacks even when the model is fooled.
