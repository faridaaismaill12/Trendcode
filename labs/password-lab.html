    2. Generate a passphrase

    Random words are easier to remember than random symbols, and just as strong if there are enough of them. The words are picked with your browser's cryptographic random generator.

    Rules that actually help

    • Length beats cleverness. Swapping a for @ is the first trick crackers try. Each extra random word adds far more strength.
    • Never reuse passwords. When one site leaks, attackers try that password everywhere else. A password manager makes unique passwords painless.
    • Slow hashing protects you, if the site uses it. Compare the "fast hash" and "slow hash" rows: the same password lasts thousands of times longer. Read more in Hashing, explained.
    • Better still: no password at all. Passkeys can't be guessed, reused or phished.
